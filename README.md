## 🚀 Featured Projects

### 🌦️ [Sky-cast — Weather App](https://github.com/AmerAbdla/Sky-cast)
A responsive weather application that lets users search for cities and explore current conditions, hourly and 7-day forecasts, an interactive map, rain radar, and animated wind visualization.

- **Built with:** React, React Router, Vite, Tailwind CSS, Leaflet
- **Weather data:** Open-Meteo and RainViewer
- **Live demo:** [sky-cast-blue-tau.vercel.app](https://sky-cast-blue-tau.vercel.app)

### 🦷 [Royal Dent Clinics — Clinic Website](https://github.com/AmerAbdla/RoyalDentClinicsWeb)
A modern, responsive dental clinic website with English and Arabic versions, right-to-left layout support, service information, specialist profiles, and an interactive appointment form.

- **Built with:** HTML5, CSS3, JavaScript
- **Highlights:** Responsive layout, bilingual UI, and scroll animations
- **Repository:** [View project on GitHub](https://github.com/AmerAbdla/RoyalDentClinicsWeb)
